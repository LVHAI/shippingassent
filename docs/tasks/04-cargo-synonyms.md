# 04: 货物类型同义词映射

**What to build:** 构建货物类型的同义词映射层，将用户的口语表达转换为系统中的标准术语。高频映射硬编码，确保零延迟匹配。

**Blocked by:** 01 项目脚手架与依赖配置

**Status:** ready-for-agent

## Acceptance criteria

- [ ] `agent/tools.py` 中定义 `CARGO_TYPE_SYNONYMS` 映射字典
- [ ] 实现 `normalize_cargo_type(user_input: str) -> str` 函数
- [ ] 覆盖以下高频映射：
  - "普通商品"/"没特殊要求"/"一般货物" → "普货"
  - "衣服"/"服装"/"鞋子"/"包包" → "P服装"
  - "电子产品"/"手机"/"带电池"/"笔记本" → "带电"
  - "化妆品"/"面霜"/"护肤品" → "膏体"
  - "香水"/"酒精液体" → "液体"
  - "纯电池"/"充电宝" → "纯电池"
  - "粉末"/"粉状物" → "粉末"
- [ ] 大小写不敏感匹配
- [ ] 未命中时返回原始输入（留给 LLM fallback）
- [ ] 单元测试覆盖所有高频映射 + 未命中场景

## Technical notes

- 参考 CONTEXT.md 术语表中的"货物类型"章节
- 参考 ADR-008：硬编码 + LLM fallback 策略
- 映射表应支持后续扩展（新增同义词只需添加字典条目）
