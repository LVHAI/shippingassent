# 运费助手 — 领域模型 & 术语表

## 领域概述

本系统服务于**跨境物流**行业的运费报价场景。用户（业务员）需要根据目的国、货物重量、货物类型，从数百个物流渠道中找到最合适的报价方案。

## 术语表

### 产品与渠道

| 术语 | 英文 | 定义 | 示例 |
|------|------|------|------|
| **产品类别** | Product Category | 物流服务的三大分类 | 专线小包、邮政系列、国际快递 |
| **渠道** | Channel | 具体的物流服务产品，是报价的最小单元 | ED美线免税小包-普货(AQ) |
| **路向/大区** | Region | 渠道覆盖的地理区域 | 欧洲、美洲、亚洲、中东 |
| **专线小包** | Dedicated Line Parcel | 针对特定国家/地区的专线物流，通常双清包税 | 美国专线小包、巴西专线小包 |
| **邮政系列** | Postal Service | 通过各国邮政系统寄送的服务 | E邮宝、EMS、荷兰邮政小包 |
| **国际快递** | International Express | DHL/FedEx/UPS 等国际快递公司的代理服务 | 香港DHL代理价、大陆联邦小货 |

### 计费相关

| 术语 | 英文 | 定义 | 计算方式 |
|------|------|------|---------|
| **运费/KG** | Price per KG | 每公斤的运输单价 | 运费 = 重量(KG) × 运费/KG |
| **处理费** | Handling Fee | 每票固定的操作处理费用 | 每票收取固定金额 |
| **总价** | Total Price | 单次发货的总运费 | 总价 = 重量 × 运费/KG + 处理费 |
| **首重** | First Weight | 首重+续重计费模式中的基础重量和价格 | 首0.5KG 77元 |
| **续重** | Additional Weight | 超过首重后，每续重单位的加价 | 每续0.5KG 加21元 |
| **起重** | Minimum Weight | 渠道接受的最低发货重量 | 起重50g |
| **限重** | Maximum Weight | 渠道接受的最高发货重量 | 限重30kg |
| **体积重** | Volumetric Weight | 按包裹体积折算的重量 | 长×宽×高(cm) / 8000 = KG |
| **实重** | Actual Weight | 包裹的实际称重重量 | 电子秤称重 |
| **计费重** | Chargeable Weight | 用于计算运费的重量 | max(实重, 体积重) |

### 货物类型

| 术语 | 英文/缩写 | 定义 | 备注 |
|------|----------|------|------|
| **普货** | General Goods | 无特殊属性的普通商品 | 大多数渠道可接 |
| **P货/P服装** | Branded Goods | 仿牌/品牌服装鞋包 | 部分渠道可接，部分拒收 |
| **带电/内置电** | With Battery | 含电池或电子元器件的商品 | 需走特定渠道 |
| **纯电池** | Pure Battery | 独立电池产品 | 仅少数渠道可接 |
| **液体** | Liquid | 液态商品（化妆品、香水等） | 部分渠道可接，有限制 |
| **膏体** | Paste/Cream | 膏状化妆品等 | 部分渠道可接 |
| **粉末** | Powder | 粉状商品 | 大多数渠道拒收 |
| **特货** | Special Goods | 敏感货物的统称 | 需走特货渠道 |

| 术语 | 英文 | 定义 |
|------|------|------|

| **DDU** | Delivered Duty Unpaid | 收货方承担进口关税和清关费用 |
| **时效/参考时效** | Transit Time | 预计从发货到签收的天数范围 |
| **妥投率** | Delivery Rate | 包裹成功送达的比例 |
| **承运商** | Carrier | 目的国末端配送的物流公司 |
| **产品ID** | Product ID | 易德内部系统中标识渠道的编号 |

### 尺寸与限制

| 术语 | 定义 |
|------|------|
| **最大尺寸** | 包裹外包装的最大允许尺寸（长×宽×高 cm） |
| **最小尺寸** | 包裹外包装的最小允许尺寸 |
| **三边之和** | 长+宽+高 的总和限制 |
| **偏远地区** | 承运商定义的偏远区域，需收取额外附加费 |
| **偏远附加费** | 寄往偏远地区时额外收取的费用 |

### 业务流程

| 术语 | 定义 |
|------|------|
| **冲货** | 将禁运品或不符合渠道要求的货物混入发货 |
| **低申报** | 故意低报货物价值以逃避关税 |
| **退件** | 因各种原因将包裹退回发件人 |
| **重派** | 退回后重新安排发货 |
| **赔付** | 货物丢失/损坏时的赔偿流程 |
| **预报下单** | 在系统中预先录入发货信息 |
| **上网** | 包裹被承运商扫描录入系统，开始有物流轨迹 |
| **清关** | 货物通过海关检查的过程 |
| **扣关** | 海关因各种原因扣留货物 |

## 业务规则摘要

### 计费规则

1. **运费/KG + 处理费**模式：`总价 = 重量(KG) × 运费单价 + 处理费`
2. **首重 + 续重**模式：`总价 = 首重价格 + ceil((重量 - 首重) / 续重单位) × 续重价格`
3. 计费重取 **实重** 和 **体积重** 的较大值
4. 低于起重的包裹按起重计费

### 渠道匹配规则

1. 先按 **目的国家** 筛选可用渠道
2. 再按 **货物类型** 筛选（普货渠道不接带电/液体/P货等）
3. 再按 **重量范围** 筛选（起重 ≤ 重量 ≤ 限重）
4. 检查 **尺寸要求** 是否满足
5. 如有多个匹配渠道，可按价格或时效排序推荐

### 禁运规则

1. 航空禁运物品适用于所有渠道
2. 各渠道有独立的接货类型限制
3. 冲货罚款 5000元/票，不退运费不退货
4. 违禁品（仿牌、枪支、弹药、毒品等）移交公安机关
